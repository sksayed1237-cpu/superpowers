# Superpowers Core Guidelines

Invoke relevant or requested skills BEFORE any response or action — including clarifying questions, exploring the codebase, or checking files.

- **Creative Work & New Features**: Invoke `brainstorming` before implementation or entering plan mode.
- **Bug Fixing**: Invoke `systematic-debugging` before proposing fixes.
- **Implementation**: Follow `test-driven-development` (TDD) and `subagent-driven-development`.
- **Planning**: Invoke `writing-plans` and track tasks via task artifacts.
- **Reference**: See the `using-superpowers` skill for complete workflow details and Antigravity tool mappings.
